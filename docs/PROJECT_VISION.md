# 1. 为什么做这个项目？

## 背景

目前优秀教育资源主要集中在大城市。

普通县城、小城市的孩子：

- 接触不到优秀老师
- 没有丰富兴趣班
- 缺少长期陪伴
- 家长没有足够时间辅导

AI第一次有机会缩小这种差距。

我们希望让普通家庭的孩子，也拥有一位能够长期陪伴成长的 AI。

# 7. 产品原则（必须遵守）

P1：

任何功能，都必须让孩子更愿意明天打开App。

P2：

任何学习内容，都应该隐藏在故事和探索中。

P3：

永远不要让孩子觉得自己在上课。

P4：

AI永远引导，而不是直接告诉答案。

P5：

兴趣比成绩更重要。

P6：

成长比考试更重要。
